# UCI real-consumption dataset (converted)

Files generated by `scripts/convert_uci_electricity.py` from:

> Trindade, A. (2015). *ElectricityLoadDiagrams20112014*. UCI Machine Learning
> Repository. https://doi.org/10.24432/C58C86. Licence: CC BY 4.0.

* **Real:** the electricity consumption of 264 anonymised customers of a
  Portuguese utility, measured every 15 minutes in 2011–2014 and summed into
  9859 monthly meter readings.
* **Synthetic:** names, municipalities, addresses, account numbers and meter
  serials. UCI publishes only anonymous IDs (MT_001 … MT_370). **These are not
  real Timorese customers.** No phone numbers are included, and e-mails use
  `@example.invalid`.
* **Dates:** shifted forward (see each record's notes) so they fall inside the
  app's tariff periods.
* Customers averaging more than the `--max-avg-kwh` threshold (default
  200,000 kWh/month) are left out so totals stay at Timor-Leste scale. They are
  listed in `excluded_large_customers.csv` when present.
* Customer type and tariff category come from the real consumption size:
  up to 1,500 kWh/month is residential, larger is commercial, with a few
  assigned to public facilities.

Import in this order: customers → accounts → meters → readings.
Every row is imported with the demo flag, so the app labels it as demonstration data.
